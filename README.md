## 🎮 Sobre o Projeto

O **Code Junior** é um jogo desenvolvido como Trabalho de Conclusão de Curso (TCC) com o objetivo de facilitar o aprendizado de programação para iniciantes. Através de fases desafiadoras e conteúdo didático, os jogadores são introduzidos aos conceitos fundamentais da programação de forma lúdica e engajante.

## ✨ Funcionalidades

- **Aprendizado Progressivo**: Conteúdo dividido em fases que evoluem em complexidade
- **Jogabilidade Interativa**: Aprenda programação de forma prática e divertida
- **Interface Amigável**: Design intuitivo e acessível para todas as idades
- **Conceitos Fundamentais**: Aborda os principais tópicos da programação de forma didática

## 🚀 Como Jogar

1. Clone este repositório:
   ```bash
   git clone https://github.com/Elitinho123456/TCC-Programacao-Para-Todos.git
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd TCC-Programacao-Para-Todos
   ```
3. Abra o arquivo `index.html` em seu navegador preferido
4. Navegue pelo menu inicial para conhecer as fases disponíveis
5. Complete os desafios de cada fase para avançar
6. Aprenda conceitos de programação de forma prática
